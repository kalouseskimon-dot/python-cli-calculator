# CLI Calculator in Python

A robust, interactive command-line calculator built with Python. Designed with input validation, error handling for mathematical edge cases, and clean terminal user interaction.

## Features

- **Standard Operations:** Addition, Subtraction, Multiplication, Division.
- **Error Handling:** 
  - Prevents crash on division by zero (`ZeroDivisionError`).
  - Validates float inputs to prevent crashes on non-numeric entries (`ValueError`).
  - Rejects unsupported mathematical operators.


## Requirements

- Python 3.8 or higher.
